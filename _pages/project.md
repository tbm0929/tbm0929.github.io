## 🚀 Projects

**GitHub Profile & Academic Portfolio** *(April 2026)*  
Built out this GitHub Pages site to document my transition from enterprise IT into 
data science and applied AI. Converted a 25-year professional resume into structured 
Jekyll markdown, including an About page, skills table, and certifications — all 
formatted for the Minimal Mistakes theme.

**Local LLM Deployment — Qwen3** *(Ongoing)*  
Deployed Qwen3 on personal consumer-grade gaming hardware to study large language 
model behavior outside of cloud environments. Exploring inference performance, prompt 
sensitivity, and real-world constraints that don't show up in API-based workflows. 
This work directly informs my graduate research in machine learning and NLP at UHCL.

**Mobile Robotics — ROS2, RViz, TurtleBot3 & Gazebo** *(Ongoing)*  
Hands-on robotics work using the ROS2 framework to program, simulate, and visualize 
autonomous robot behavior. Built and configured TurtleBot3 navigation stacks, used 
Gazebo for physics-based environment simulation, and leveraged RViz for real-time 
sensor and transform visualization. Projects span topics like autonomous navigation, 
SLAM (Simultaneous Localization and Mapping), and robot state monitoring — bridging 
my background in systems infrastructure with emerging work in intelligent autonomous 
systems.
